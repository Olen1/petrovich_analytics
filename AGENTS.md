# petrovich_analytics — правила для агентов

Продуктовая аналитика «Петровича» — ИИ-ассистента владельца грузового автопарка на телематике AutoGRAPH
(заказчик — «Техноком»). Кода продукта нет: документы на русском и скрипты проверки. Код приложения и стенда —
в соседнем репозитории `../petrovich`; что реально реализовано, сверяйте по нему.

## Команды

| Что | Команда | Вердикт |
|---|---|---|
| Проверить всё: документы, слоп, диаграммы, слайды | `npm run check` (или `-- doc/<файл>.md`) | exit 0 — прошло, exit 1 — список ошибок |
| Нейрослоп подробно, с подсказками | `npm run slop -- <файл>` | exit 1 — есть жёсткие маркеры |
| Отрисовать Mermaid-диаграммы | `npm run render -- <файл>` | exit 2 — не проверено (нет браузера или сети) |
| Собрать и проверить слайды | `npm run slides -- slides/<имя>.json` | вёрстка за краем, диаграммы, слоп |
| Собрать отчёт по спринту (.pptx) | `npm run sprint-deck -- slides/sprint_<N>.json` | вёрстка за краем, схема, слоп |
| Окружение и обвязка | `npm run doctor` | exit 0 / exit 1 |

Перед тем как сказать «готово», `npm run check` должен пройти. «НЕ ПРОВЕРЕНО» — не «прошло»: скажите пользователю.

## Конвенции

- Русский язык, короткие предложения, конкретика: числа с единицами, даты, методы API.
- Шапка: `# Заголовок`, следующей строкой `_Статус: … | Версия: X.Y | Дата: ГГГГ-ММ-ДД_`.
  В `doc/Analiz/` исторически `_Версия X.Y · ДД.ММ.ГГГГ · …_` — формат файла сохраняется.
- Изменили содержание — поднимите версию (правка +0.1, перестройка +1.0) и дату.
- `[Значение в скобках]` — гипотеза. Без источника скобки не снимать.
- Приоритеты — MoSCoW (M / S / C / W). Чего нет во вводных — в «Открытые вопросы», не додумывать.
- Ссылка на документ — с версией: `brd_mobile_mvp.md` v0.2. Ссылка на удалённый документ — со словом «удалён».
- Без нейрослопа: никаких «важно отметить», «не просто X, а Y», «мощный инструмент» — `npm run check` их ловит.
- Процесс, статусы, взаимодействие систем — диаграммой Mermaid в документе (```mermaid), до 15 узлов.

## Границы

- Свободно: читать всё, править `doc/`, `.claude/`, `scripts/`, `*.md` в корне.
- С подтверждением пользователя: коммит, push, удаление файлов, удаление требований и решений из BRD.
- Запрещено: править исходные материалы; писать ключи, пароли, логины AutoGRAPH; необратимые git-команды
  (`push --force`, `reset --hard`, `clean -f`) — их блокирует хук.
- Приоритеты требований меняет Product Owner. Агент выносит расхождение в вопросы, а не решает сам.
