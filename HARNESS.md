# Канвас обвязки: petrovich_analytics
_Статус: действует | Версия: 1.1 | Дата: 2026-10-19_

Обвязка собрана по лекции «Harness-обвязка проекта» (Сбер): **правила + автоматика + проверяемость**.
Уровень зрелости — **L3 «Скиллы и хуки»**: правила, команды проверки с вердиктом, скиллы, хуки-границы.

## Канвас

| Поле | Что сделано | Где |
|---|---|---|
| **Проект** | Документы продуктовой аналитики «Петровича»: BRD, экраны, исследования. Агент пишет и сверяет документы, а не код | — |
| **Правила** | Страница правил на две минуты: команды, структура и карта документов, конвенции, границы, грабли. `AGENTS.md` — для любых агентов, `CLAUDE.md` подключает его и добавляет своё | `AGENTS.md`, `CLAUDE.md` |
| **Команды** | Одна команда проверки всего и одна — окружения, обе с вердиктом exit 0 / exit 1. Отдельно: подробный отчёт о слопе, рендер диаграмм, сборка слайдов | `npm run check`, `doctor`, `slop`, `render`, `slides` |
| **Скиллы** | Повторяемые операции: BRD по шаблону, новый документ, вычитка, антислоп, диаграмма в документе, слайды из документа, сверка документов | `.claude/skills/` |
| **Визуализация** | Диаграммы Mermaid хранятся в документах как текст. Слайды собираются из одного источника `slides/*.json` в стиле приложения; рендер проверяется в безголовом Edge или Chrome, без npm-пакетов | `slides/`, `scripts/slides/` |
| **Хуки** | До записи: исходные материалы, чужие папки, секреты. До команды: необратимые git и rm. После правки: шапка и версия. На завершение: `npm run check` по изменённым документам | `.claude/hooks/`, `.claude/settings.json` |
| **Интеграции** | Субагент `doc-reviewer` для независимого ревью. MCP пока не подключены: кандидаты — Google Drive (исходники команды) и трекер задач, только чтение | `.claude/agents/` |
| **Права** | Свободно: чтение, правка `doc/`, просмотр git, команды проверки. С подтверждением: коммит, push, удаление. Запрещено: правка исходных материалов, личные настройки и секреты | `.claude/settings.json` |
| **Память** | Решения пользователя и грабли между сессиями | `DECISIONS.md` |
| **Метрики** | См. ниже | — |

## Что проверяет `npm run check`

| Проверка | Против какого антипаттерна |
|---|---|
| Шапка: заголовок, версия, дата | Документ без версии — не понять, на что ссылаться |
| Ссылки на файлы существуют, версии в ссылках совпадают с шапкой | Ссылки на устаревшие редакции |
| Каждый файл `doc/` есть в карте `AGENTS.md`, и наоборот | Обвязка-музей: правила описывают прошлое |
| Нет ключей, паролей, токенов в документах и правилах | Секреты в правилах |
| `AGENTS.md` и `CLAUDE.md` не длиннее ~900 слов | Правила-роман |
| Нейрослоп: 13 жёстких шаблонов — ошибка, усилители и канцелярит — предупреждение выше 6 на 1000 слов | Текст модели без редактуры |
| Mermaid-диаграммы: тип, скобки, кавычки, размер (полная отрисовка — `npm run render`) | Диаграмма, которая не рисуется |
| Слайды: схема и лимиты текста, слоп, HTML собран из текущего JSON, источник не обновился после сборки | Слайды разошлись с документом |

`npm run slides` дополнительно рендерит колоду и ловит текст за краем слайда и ошибки диаграмм.

## Метрики: как понять, что обвязка работает

| Метрика | Как считать | Цель |
|---|---|---|
| Документы с первой попытки | Доля правок, принятых без переделки | `[≥ 70 %]` |
| Ошибки `npm run check` в коммитах | Прогон по каждому коммиту | 0 |
| Повторные объяснения | Сколько раз за сессию пришлось объяснять уже записанное в правилах или `DECISIONS.md` | 0 |
| Срабатывания хуков | Сколько блокировок было и сколько из них ложных | ложных — 0 |
| Свежесть правил | Дней с последней правки `AGENTS.md` при изменениях в `doc/` | правится в той же правке |
| Слоп в принятых документах | Жёстких маркеров в `npm run slop` по `doc/` | 0 |
| Слайды с первой сборки | Доля колод, прошедших `npm run slides` без правок вёрстки | `[≥ 50 %]` |
