# MVP: ИИ-агент «Петрович» — описание реализованного прототипа
_Дата: 2026-09-12_

---

## Что такое MVP

Веб-интерфейс для управления автопарком с ИИ-агентом «Петрович».
Целевой пользователь — аналитик или руководитель автокомпании.
В demo-базе: 8 транспортных средств.
Бэкенд: PostgreSQL + REST API (Swagger-документация по `/docs`).
Карты: 2ГИС. Графики: Chart.js.

---

## Разделы интерфейса

### 1. Источник данных
Два способа подключить телематику:
- **Файл** — загрузка xlsx или csv. Поддерживаемые форматы: Skaut, Omnicom, произвольный CSV с колонками `ts, lon, lat, speed, fuel_total, eng_hours, move_state`
- **AutoGRAPH (Technokom)** — прямая синхронизация: выбор схемы, диапазон в днях, превью данных

### 2. Аналитика
- Выбор конкретного ТС
- **График сырых точек**: уровень топлива + моточасы, диапазоны 12ч / 24ч / 3д / 7д / всё, постраничная навигация
- **График дневных агрегатов**: факт расхода vs прогноз
- **Карта трека** на 2ГИС с фильтром по датам
- **Сводная таблица по дням**: пробег (км), расход (л), прогноз (л), отклонение (%), холостой ход (ч), рабочие часы, л/моточас
- Экспорт в CSV — по точкам и по дням

### 3. Аномалии
- Запуск детектора по кнопке
- Три уровня серьёзности: **High / Med / Low**
- Три статуса жизненного цикла: **New / Resolved / Dismissed**
- Пагинация списка

### 4. Чат с Петровичем
- Запрос на естественном языке
- Ответ стримится по мере генерации LLM
- Переключатель «Использовать LLM» — fallback-режим без модели

### 5. Расписание утреннего доклада
- Список подписчиков Telegram (Chat ID, имя, время)
- Cron: **09:30 Asia/Yekaterinburg**
- Отправка всем подписчикам или одному конкретному
- Превью отчёта прямо в интерфейсе
