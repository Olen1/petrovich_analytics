@AGENTS.md

## Только для Claude Code

**Скиллы** (`.claude/skills/`):
- `/petrovich-brd` — собрать или обновить BRD по шаблону `SKILL/make-bizness-treb`.
- `/new-doc` — завести новый документ: шапка, место, карта в AGENTS.md.
- `/text-check` — вычитать текст документа по чек-листу, до и после правки.
- `/deslop` — убрать нейрослоп: `npm run slop` плюс ручной чек-лист оборотов, которые скрипт не ловит.
- `/diagram` — нарисовать процесс, статусы или взаимодействие Mermaid-диаграммой в документе.
- `/doc-slides` — собрать слайды из документа в стиле приложения «Петрович».
- `/doc-consistency` — сверить документы между собой: числа, сроки, гипотезы, дубли.
- `/petrovich-changes` — вычитать новые коммиты `../petrovich` и дописать их в журнал `doc/petrovich_changes.md`.
- `/sprint-review` — отчёт по спринту в .pptx по шаблону «Петрович_итоги_1_спринта_v11»: план против факта по коммитам `../petrovich`, что сделано, задачи на следующий спринт, заметки докладчика.

**Субагенты** (`.claude/agents/`):
- `doc-reviewer` — независимое ревью документа против источников, только чтение.
- `business-analyst` — зачем и что: BRD, пользовательские истории, гипотезы и метрики, вопросы PO; пишет в `doc/`.
- `system-analyst` — как: AutoGRAPH API, контракты `fleet_service`, данные и расчёты, НФТ, сверка с кодом `../petrovich`; пишет в `doc/`.

**Хуки** (`.claude/hooks/`, настроены в `.claude/settings.json`) срабатывают всегда:
- до записи файла — блок исходных материалов, записи вне разрешённых папок и секретов;
- до команды — блок необратимых команд;
- после правки документа — проверка шапки и напоминание про версию;
- на завершение — `npm run check` по изменённым документам и слайдам; не прошло — работа продолжается.

Хук заблокировал действие — не обходите его другим инструментом: исправьте причину или спросите пользователя.
