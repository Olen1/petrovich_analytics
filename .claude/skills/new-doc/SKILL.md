# Новый документ

1. Папка: требования и спецификации — `doc/`, исследования (интервью, рынок, CJM, сегменты) — `doc/Analiz/`.
2. Имя файла — латиницей, `snake_case`, без версии в имени: `interview_owners.md`.
3. Шапка — две строки:
   ```
   # <Заголовок по сути: что в документе>
   _Статус: черновик | Версия: 0.1 | Дата: <сегодня, ГГГГ-ММ-ДД>_
   ```
4. Первый абзац — вывод или назначение документа одним-двумя предложениями. Ниже — источники с версиями:
   `brd_petrovich_mvp_full.md` v1.1.
5. Добавьте строку в таблицу «Структура» в `AGENTS.md`: путь и что это.
6. Если документ — следствие решения пользователя, добавьте строку в `DECISIONS.md`.
7. Запустите `npm run check -- <путь>` и `/text-check`.
