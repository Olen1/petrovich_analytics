# Слайды из документа

Источник один — `slides/<имя>.json`; `slides/<имя>.html` собирается из него командой и руками не правится.
Пример — `slides/brd_mvp_overview.json`.

## 1. До слайдов

Выясните (или возьмите из запроса): **кто смотрит** (заказчик, команда, защита) и **какое решение** должен
принять зритель. От этого — что оставить. Колода — 6–12 слайдов, одна мысль на слайд.

## 2. Структура JSON

```json
{ "title": "…", "brand": "Петрович", "sources": ["doc/<файл>.md vX.Y"], "slides": [ … ] }
```

| type | Поля | Когда |
|---|---|---|
| `title` | title, subtitle?, meta? | Первый слайд; в meta — источник с версией и дата |
| `section` | title, num?, lead? | Разделитель в колоде от 10 слайдов |
| `statement` | title, text, lead?, takeaway? | Одна главная мысль крупно: проблема, решение |
| `metrics` | title, items: [[число, подпись]] ×2–4, takeaway? | Ключевые числа |
| `bullets` | title, items ≤ 6, takeaway? | Однородный перечень |
| `cards` | title, items: [[заголовок, текст]] ×2–4, takeaway? | Варианты, сегменты, модули |
| `table` | title, head ≤ 5, rows ≤ 7, takeaway? | Сравнение, было → стало, план |
| `diagram` | title, mermaid, caption? | Поток, статусы, взаимодействие — правила скилла `/diagram` |

В тексте: `**жирный**`, метки серьёзности `[[high:High]]`, `[[med:Medium]]`, `[[low:Low]]`, `[[ok:Норма]]`.

## 3. Правила содержания

- Каждое число, срок и приоритет — из источника, с той же оговоркой: гипотеза остаётся в `[скобках]`.
- Заголовок слайда — вывод, а не тема: «Слив находят через 3–10 дней», а не «Проблема».
- `takeaway` — что зритель должен запомнить, одной строкой. Не пересказ слайда.
- Не смешивать: приоритеты MVP — только из §4 и §8.1 BRD, не из Приложения А.

## 4. Сборка и проверка

1. `npm run slides -- slides/<имя>.json` — схема и лимиты, нейрослоп, рендер в браузере: текст за краем
   слайда и ошибки диаграмм. Нужен ВЕРДИКТ: ПРОШЛО.
2. Ошибка вёрстки — сократить текст или разбить слайд. Не уменьшать шрифт и не менять шаблон ради одного слайда.
3. `/deslop` по JSON, затем пересобрать.
4. Пользователю: путь к HTML. Открыть — двойным щелчком; листать — стрелками; PDF — печать браузера (Ctrl+P →
   «Сохранить как PDF», поля — нет).
5. Источник обновился — `npm run check` покажет, что колода собрана по старой версии: сверить слайды с изменениями,
   поднять версию в `sources` и `meta`, пересобрать.

Шаблон — `scripts/slides/template.html` (цвета и шрифты из темы приложения). Изменили шаблон — пересоберите все колоды.
