# Вычитка текста

Пройдите чек-лист **дважды**: после первого прохода исправьте, затем проверьте исправленное ещё раз.
Ничего не меняйте по смыслу: только формулировки. Сомневаетесь в факте — вынесите в «Открытые вопросы».

1. **Вывод первым.** Первое предложение документа и каждого раздела — главный вывод или решение, а не
   «В документе рассматривается…».
2. **Конкретика.** Числа с единицами (₽, мин, ТС, %), даты, имена методов API. Прилагательные без числа
   («быстро», «значительно») — заменить числом или гипотезой `[…]`.
3. **Гипотезы.** Каждое целевое значение без источника — в `[скобках]`. Скобки не сняты без подтверждения.
4. **Предложения.** Короче 25 слов, абзац — до 3 предложений. Списки — только для однородных пунктов.
5. **Вода.** Убрать «важно отметить», «следует подчеркнуть», «в рамках данного», повторы раздела в выводах.
6. **Термины.** Как в глоссарии BRD §9.1: ТС, ДУТ, High / Med / Low, «Ложная тревога».
7. **Ссылки.** На другие документы — с версией; `npm run check -- <файл>` проходит.

Итог для пользователя: сколько правок по каждому пункту и что вынесено в вопросы.
